# pulse_registry.txt — какие периодические задачи обязаны ДОСТАВЛЯТЬ результат.
#
# Скопируй этот файл в System/memory/pulse_registry.txt и заполни под свой проект.
# По строке на задачу, три поля через |:
#
#   метка | путь к репозиторию | ^якорный-шаблон-коммита
#
# Путь: абсолютный либо относительный от корня проекта («.» — текущий проект).
# Якорь: обязательно с ^ в начале. Без ^ детектор поймает коммит, который лишь
# УПОМИНАЕТ фразу (например, жалобу сторожа «weekly digest не вышел») и решит,
# что доставка была. Это проверено тестом в smoke_hooks.sh.
#
# Задача попадает сюда, только если она КАЖДЫЙ цикл гарантированно пишет
# датированный файл и коммитит его. Задача без детерминированной доставки
# этим детектором не проверяется — и это честнее, чем зелёная галочка.
#
# Примеры (удали и замени своими):
# недельная сводка | . | ^weekly digest
# аудит подопечного | ../Другой проект | ^weekly care
